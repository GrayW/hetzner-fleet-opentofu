Fleet on Hetzner config helper

Answer a few questions and get a ready-to-use terraform.tfvars file, plus step-by-step instructions for hetzner-fleet-opentofu.

Nothing you type leaves this page. There is no server behind it, and your browser is told to block every outgoing request.

Before you start

You need three things ready. Tick each one when you have it.

You can keep going, but you’ll need all three before you deploy.

Domain and email

The address people will use to open Fleet, such as fleet.yourcompany.com. You’ll add DNS records for it later.

Let’s Encrypt emails this address if your HTTPS certificate is about to expire.

Server

Location

Pick the one closest to the devices that will connect.

Size

The default suits a lab or up to about 50 devices.

Not every size is available in every location. If deploying fails with resource_unavailable, try another size or location.

Fleet

Use a specific version such as v4.91.1, not “latest”, so every deploy is repeatable.

Edition

Software packages

Fleet can store software installers in Hetzner Object Storage. This is optional, and you can add it later.

If you turn this on, you’ll create access keys in the Hetzner Console under Object Storage, then Access Keys. The next step covers how to enter them safely.

Secrets

Your Hetzner API token can control your whole cloud account. The safest approach keeps it out of every file and out of this page.

How to handle secrets

Treat the finished file like a password.

Anyone who gets it can use your Hetzner account. Don’t commit it, email it, or paste it into a chat. What you type below stays in this browser tab and goes into the file only when you copy or download it.

Your files and instructions

Copy or download terraform.tfvars from the panel next to this (below it on a phone). Then follow the steps.
